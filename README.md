# Basic POS System

This is a simple four-page Point-of-Sale website created using CodeIgniter 4. It shows how routes, controllers, and views work together using the MVC structure.

## Pages

- Home page
- About page
- Customer Accounts page
- User Accounts page

The Customer Accounts and User Accounts pages use static PHP arrays as temporary data sources. No database is used in this version.

## Requirements

- PHP 8.1 or higher
- Composer
- CodeIgniter 4

## Installation

1. Clone or download this repository.
2. Open a terminal inside the project folder.
3. Install the required packages:
